# Atendly — especificação de marca aplicada

Fonte: `DESIGN.md`. Conversão para OKLch mantém a hierarquia visual da paleta original.

```css
:root {
  --bg: oklch(97.8% 0.004 160);
  --surface: oklch(100% 0 0);
  --fg: oklch(19.7% 0.032 252);
  --muted: oklch(54.5% 0.018 164);
  --border: oklch(91.3% 0.009 160);
  --accent: oklch(51.7% 0.119 164);

  --font-display: "Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
  --font-body: "Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
  --font-mono: "IBM Plex Mono", "SFMono-Regular", Consolas, monospace;
}
```

Regras observadas:

- superfícies claras, bordas suaves e elevação mínima;
- navy concentra hierarquia e texto principal;
- verde acessível identifica ação e sucesso; verde vivo fica restrito à marca;
- violeta identifica IA e automação, nunca a ação principal;
- ritmo editorial limpo, raios moderados e ícones lineares de 1,75–2 px.

Resumo: uma interface operacional calma, clara e premium, com verde contido sobre base branca e navy.
