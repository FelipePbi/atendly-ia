# Atendly Open Design context

Este contexto gerado deve seguir as fontes atuais, nesta ordem:

1. `../../../../docs/product-vault/00-HOME.md`;
2. `../../DESIGN.md`;
3. `../../AGENTS.md`.

Regras mínimas para qualquer geração:

- desenhar primeiro para mobile;
- usar Agenda Atendly como única agenda operacional;
- tratar Minha Agenda somente como origem da importação única;
- usar os estilos Profissional, Equilibrada e Descontraída;
- usar `IA` para a automação, sem persona ou avatar próprio;
- usar `Início | Conversas | Agenda | Clientes | Mais` na navegação mobile;
- preservar a direção visual clara, elegante, profissional e acessível definida em `DESIGN.md`.

Não derive comportamento dos HTMLs ou do manifesto existentes sem validar contra o product vault.
