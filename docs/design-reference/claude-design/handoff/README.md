# Handoff para Claude Code

Esta pasta contém a exportação nativa de handoff do Claude Design e o prompt associado à opção **Local agent**.

- `Atendly-Stage-1-delivery-handoff.zip` é o bundle original, sem alterações. Ele contém o README gerado pelo Claude Design e uma cópia completa do projeto.
- `claude-code-prompt.md` preserva o texto copiado pelo botão **Copy prompt**.

O handoff apenas prepara contexto para uma implementação futura. Nenhuma sessão de implementação foi iniciada e nenhum código React foi gerado nesta tarefa.

Antes de implementar, o agente deve ler o `docs/product-vault/`, a arquitetura atual, os contratos do backend e o README da pasta pai. O HTML/CSS/JS do bundle serve para reproduzir aparência e comportamento, não para determinar arquitetura nem para ser promovido diretamente a produção.
