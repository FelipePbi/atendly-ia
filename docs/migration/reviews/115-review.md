# Review formal — Goal 115

**Decisão vigente — rodada 2: ACCEPTED.** Tech Lead Agent ([D-018](../DECISIONS.md)), 2026-10-04, conforme o [Goal115](../goals/115-marcar-como-pessoal-so-nesta-conversa-ou-sempre-e-o-menu-do-chat-igual-ao-prototipo.md). O aceite vale só para o diff identificado abaixo. Nenhum aceite anterior foi reaberto, reavaliado ou revertido.

"Marcar como pessoal" passa a perguntar "Só esta conversa" ou "Sempre, para {nome}", e cada escolha faz o que a frase promete. A decisão por conversa mora numa coluna nova, `ConversationSession.categoryOverride` (`SessionCategory` anulável, migration aditiva `20261004120000_goal115_session_category_override`, sem backfill). A precedência é sessão, depois contato, depois sugestão, depois `UNCLASSIFIED`. `PUT /v1/conversations/{id}/category` aceita `scope` opcional (`CONVERSATION` ou `CONTACT`, padrão `CONTACT`), e a conversa devolve `categoryScope`. Sem `scope`, toda chamada faz o que a baseline fazia. O menu "•••" do chat virou a folha do K6 (`ConversationActionsSheet`) nos quatro devices. "Assumir conversa" foi para o contexto, ao lado de "Criar agendamento" e "Marcar como resolvida", e o contexto mostra de quem é a decisão de categoria. Decisão: [D-129](../DECISIONS.md), aceita neste fechamento. Ela revê o item 3 de D-128.
